# Sales Performance Dashboard

## Project Overview
An interactive Excel dashboard designed to analyse sales performance across regions, products, and time periods.

## Features
- KPI Cards
  - Total Sales
  - Total Profit
  - Total Orders

- Interactive Filters
  - Region
  - Product Category
  - Month

- Visualisations
  - Sales Trend Analysis
  - Regional Sales Comparison
  - Product Performance Analysis

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Conditional Formatting
